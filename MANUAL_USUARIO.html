Manual de Usuario - Los Atuendos

Sistema de administracion de alquiler de vestuario.

Requisitos

  • Java 11 o superior
  • NetBeans (recomendado) o Maven desde consola
  • No requiere instalar un servidor de base de datos (H2 es embebida)

Como ejecutar

Desde NetBeans

  1. Abrir el proyecto (Archivo > Abrir proyecto)
  2. Presionar F6 o clic derecho sobre el proyecto > Run

Desde consola (PowerShell)

# Compilar
& "C:\Program Files\NetBeans-14\netbeans\java\maven\bin\mvn.cmd" compile

# Ejecutar
$mvnRepo = "$env:USERPROFILE\.m2\repository"
$h2jar = Get-ChildItem -Path "$mvnRepo\com\h2database\h2" -Filter "*.jar" -Recurse | Select-Object -First 1 -ExpandProperty FullName
java -cp "target\classes;$h2jar" com.mycompany.losatuendos.LosAtuendos
La base de datos se crea automaticamente en el primer arranque como archivo losatuendos.mv.db en la carpeta del proyecto.

Pantallas y operaciones

Al abrir la aplicacion veras el menu lateral naranja con cinco modulos: Clientes, Empleados, Prendas, Servicios y Lavanderia.

Clientes

Registra y consulta clientes del alquiler.

Formulario:

  • Documento (obligatorio): numero de identificacion del cliente
  • Nombres (obligatorio)
  • Apellidos (obligatorio)
  • Telefono: numero de contacto
  • Direccion: direccion de residencia

Botones:

  • Guardar: valida los campos obligatorios y registra el cliente. Si el documento ya existe, muestra un error.
  • Limpiar: vacia todos los campos del formulario.

Tabla: muestra todos los clientes registrados con su ID asignado por la base de datos.

Empleados

Registra y consulta empleados del negocio.

Formulario:

  • Documento (obligatorio)
  • Nombres (obligatorio)
  • Apellidos (obligatorio)
  • Cargo: rol del empleado (vendedor, administrador, etc.)
  • Telefono

Botones:

  • Guardar: valida y registra el empleado
  • Limpiar: vacia el formulario

Tabla: muestra todos los empleados con su ID, cargo y telefono.

Prendas

Registra prendas de los tres tipos: vestidos, trajes y disfraces. Los campos especificos cambian segun el tipo seleccionado.

Campos comunes:

  • Tipo (lista desplegable): Vestido, Traje o Disfraz
  • Codigo (obligatorio): identificador unico de la prenda
  • Nombre (obligatorio)
  • Descripcion: detalle de la prenda

Campos para Vestido:

  • Longitud (obligatorio): corta, media o larga
  • Tiene pedreria (casilla): marca si el vestido incluye pedreria

Campos para Traje:

  • Tipo de accesorios (obligatorio): corbatin, chaleco, faja, etc.

Campos para Disfraz:

  • No tiene campos adicionales. Se identifica por su nombre.

Botones:

  • Guardar: crea la prenda usando el patron Factory y la persiste
  • Limpiar: vacia el formulario

Tabla: muestra todas las prendas con su tipo, detalle especifico y estado de disponibilidad (Si/No).

Servicios

Crea servicios de alquiler, consulta alquileres vigentes y devuelve servicios.

Formulario de creacion:

  • Cliente (lista desplegable): selecciona un cliente registrado
  • Empleado (lista desplegable): selecciona un empleado registrado
  • Prendas (lista de seleccion multiple): selecciona una o varias prendas disponibles. Las prendas no disponibles se marcan con [NO DISPONIBLE]
  • Fecha de alquiler (obligatorio): formato yyyy-MM-dd, por defecto hoy
  • Fecha de devolucion (obligatorio): formato yyyy-MM-dd, por defecto hoy +5
  • Precio total: valor numerico del alquiler

Botones:

  • Crear alquiler: valida que existan cliente y empleado, que las prendas esten disponibles para la fecha solicitada y crea el servicio con un numero consecutivo automatico. Las prendas se marcan como no disponibles mientras estan alquiladas.
  • Devolver servicio: marca un servicio como devuelto y envia sus prendas a lavanderia. Pide la fecha de devolucion y opcionalmente los IDs de prendas que requieren prioridad especial.
  • Limpiar: reinicia la seleccion del formulario

Consulta de alquileres vigentes:

  • Ingresa el ID del cliente y presiona Consultar
  • La tabla se actualiza para mostrar solo los alquileres ACTIVOS de ese cliente

Tabla de servicios: muestra ID, consecutivo, fechas, cliente, empleado, estado (ACTIVO/DEVUELTO), cantidad de prendas y precio.

Lavanderia

Gestiona las prendas devueltas que necesitan lavado, organiza tandas y marca prendas como lavadas.

Panel superior - Prendas pendientes:

  • Tabla con ID, codigo, nombre, prioridad (NORMAL o PRIORITARIA) y nivel de prioridad. Las prioritarias tienen nivel 20 (decoradas), las normales nivel 1.
  • Marcar como lavada: selecciona una prenda de la tabla y confirmala. La prenda se elimina de la cola de lavanderia y vuelve a estar disponible para nuevos alquileres.

Panel inferior - Organizar tandas:

  • Capacidad por tanda: numero maximo de prendas por tanda (por defecto 5)
  • Organizar tandas: agrupa las prendas pendientes en tandas segun la capacidad indicada. Las prioritarias se colocan primero en cada tanda, respetando el orden de llegada dentro de cada grupo de prioridad.
  • Recargar: actualiza ambas tablas

Tabla de tandas: muestra el numero de tanda, cantidad de prendas y capacidad. Tambien muestra el historial de tandas ya organizadas.
